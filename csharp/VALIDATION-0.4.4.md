## 编译与核心检查

WPF Windows x64 交叉编译、Core 编译和自带运行环境的 Host 发布全部通过，零警告、零错误。沿用已恢复的锁定依赖，未增加运行时包或在线分析服务。

真实签名包通过 **109/109** 项检查：原有 63 项，加模拟结算 20 项、整局候选比较 6 项、日志跟随 20 项。验证使用认证包内实际提取的 `Talos.Core.dll`；不是仅运行另一个源码构建后便宣称交付包通过。结果在 `dist/csharp-0.4.4/test-results.json`。

新增检查涵盖第 20 天终局、支持机制的关键结算修正、奖励覆盖后的阶段恢复、重封门新事件与当前事件共存、已探明与未知事件隔离、共同随机种子复现、配对误差、取消和预算中止。未完成的模拟轨迹不计入结果，计算失败不自动替换成即时评分。

日志检查涵盖只追新增内容、UTF-8 逐字节与半行、文件截断/替换、读取缺口、共享写入、停止取消、连续操作合并及超时。测试发现并修正了当前 Linux 文件系统创建时间随追加改变导致的误重放，未删除或放宽失败断言。

## 集成与截图检查

独立源码审查的 **23 项**断言通过并绑定最终源文件哈希。重点核对新图/日志缺口立即清除建议、句柄与进程身份、取消与过期结果保护、截图失败不无限重试、无自动联网、设置在 `data`，以及“已探明”字段从界面到模拟输入的保留。记录在 `integration-review.json`。

截图模块单独完成 WPF 编译及 6 项纯像素有效性检查，黑图和无效图不作为成功识别。其证据在 `capture-review.json`；这些像素检查没有调用 Windows 截图 API。

完整 EXE 内 380 个 bundle 条目均不要求 .NET 临时自解压，5 个旁置运行库与官方已缓存运行环境匹配。内嵌公钥、签名 JSON 和初始 ZIP 的哈希匹配测试材料。完整 ZIP 的 11 个文件、离线外包的签名 JSON 与内包均逐项比对；0.4.2 和 0.4.3 已有包及签名文件哈希保持原值。

完整包约 60.5 MB，离线更新外包约 1.3 MB。校验值在 `dist/csharp-0.4.4/SHA256SUMS.txt`，最终材料及源码哈希绑定在 `delivery-report.json`。
