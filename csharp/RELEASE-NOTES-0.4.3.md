# TalosHelper 0.4.3 界面更新

统一主界面、悬浮窗和更新窗口的深色配色、圆角卡片、文字层级与主次按钮，修正旧版黑底黑字、亮白表格和信息拥挤的问题。截图、牢房核对及刑具奖励分成三个步骤；截图前显示操作提示，数据路径和详细说明收进可展开区域。输入、表格、下拉菜单、勾选状态和滚动条使用统一主题。

窗口按可用工作区调整，较长内容可滚动。保留 F8 截图、16 格核对、离线建议、便携数据目录及更新窗口取消/关闭修复。线上版本比本机旧时不提供降级安装，同版仅在文件异常时允许修复；回退仍通过独立按钮。

已有 0.4.2 便携版可使用离线小更新：解压 `TalosHelper-CSharp-0.4.3-Offline-Update.zip`，在原程序的“检查更新”窗口点“离线导入签名文件与ZIP”，先选择其中的 JSON，再选择更新 ZIP；安装后点“重启到当前启用版本”。无需替换启动器或删除 data。

首次使用可下载完整 Windows x64 ZIP，完整解压并保留所有 DLL 后运行 `TalosHelper.exe`。截图、核对和建议保持离线。

本次只修改界面组件；规则、识图模板、启动器、存储和更新协议保持 0.4.2。编译及签名更新检查完成后随包提供验证记录。云端没有执行 Windows WPF，窗口观感、DPI 和键盘交互需 Windows 实机确认。
