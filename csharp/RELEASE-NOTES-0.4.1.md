# TalosHelper 0.4.1 C# 测试版

修复更新窗口的退出行为：空闲时“取消 / 返回助手”可用；有任务时可取消操作。关闭更新小窗口后恢复并激活助手主界面，保留正常或最大化状态。更新窗口不再有最小化/最大化按钮或独立任务栏入口，重复点击更新会回到同一个窗口。

0.4.0 用户无需重新下载完整包：在程序中点击“检查更新”→“检查更新”→“下载并安装此更新”→“重启到当前启用版本”。本次只下载约 1.3 MB 的应用更新。仍保留本地旧版本供离线回退。

首次使用请先下载 [0.4.0 完整 Windows 包](https://raw.githubusercontent.com/Sakimie/torchlightinfinite/4687e95798832047caeaefbb795a37e747a2bfef/csharp/TalosHelper-CSharp-0.4.0-Windows-x64.zip)，解压后按上述步骤更新。应用更新 ZIP 不是完整安装包，不要单独解压运行。

本次只更改界面组件，规则、识图数据、启动器和内置运行环境均沿用已发布版本。截图与建议离线运行，仅手动检查和下载更新时联网。

已进行 WPF Release 编译、真实签名包检查及公开通道从 0.4.0 升级和离线回退验证。云端未执行 Windows EXE；此次关闭、取消、快捷键及焦点行为仍需 Windows 实机回归。
