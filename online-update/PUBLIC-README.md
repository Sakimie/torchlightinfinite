# TalosHelper 更新下载

Windows 游戏截图与策略建议助手的更新通道。这里提供试用版更新包和更新说明。

## 第一次启用更新功能

从 [最新版本](https://github.com/Sakimie/torchlightinfinite/releases/latest) 下载 `TalosHelper-Online-Update-0.3.3.zip`，解压到已有的完整 TalosHelper 文件夹，与 `TalosHelper.exe`、`_internal`、`runtime` 同级。以后双击 `TalosHelper-启动器.exe`。

这是升级包，需配合原完整 v0.3 运行环境；不能单独解压到新文件夹启动。请保留原来的运行库和 licenses。

已经装过 0.3.2 的用户也需解压本版首次包，更换启动器中的旧下载地址；原本地版本保留，随后点击“检查更新”安装 0.3.3。

## 后续更新

在启动器点击“检查更新”，查看版本说明后点“下载并安装”。只下载版本程序和策略组件，不重新下载运行库。已启动的游戏助手保持运行，下一次从启动器打开时使用新版本。可以回退到保留的前版，也可以导入已签名本地包。

截图、识别、人工核对与建议始终离线；只有手动检查和下载更新才联网，不上传截图。朋友不需要 Git、Python 安装器或 GitHub 账号。

## 试用范围

0.3.3 将更新地址切换到当前公开仓库，沿用 0.3.1 已复验的策略基线与修正规则。截图后仍需核对棋盘、天数、阶段、刑具和事件，再计算下一步。建议来自模拟器启发式策略，不保证游戏中的全局最优。

本版本做了包结构与本地 Tk/Node 集成验证，尚需 Windows 电脑确认启动、实际游戏截图和 DPI 显示。

客户端使用固定发布公钥校验 Ed25519 签名，并校验下载包和组件的 SHA256。`latest.json` 是签名版本清单，`TalosHelper-<版本>-update.zip` 是更新器读取的小版本包。
