- 首次使用：下载 **TalosHelper-Online-Update-0.3.2.zip**，全部解压到原程序目录，以 **TalosHelper-启动器.exe** 启动。
- 游戏截图、识别和建议始终离线；只有手动检查、下载更新时联网。
- 下载和文件校验成功后才切换版本；保留旧版，并支持回退。更新期间不替换正在运行的程序。
- 使用签名清单和 SHA256 校验；朋友不需要 Git 或 GitHub 账号。
- 沿用 0.3.1 的策略基线与修正规则，截图后仍需人工核对状态。本次没有新增训练效果。

此升级包依赖原目录内的 `_internal`、`runtime`、`assets` 等文件，不能作为独立安装包。`latest.json` 和 `TalosHelper-0.3.2-update.zip` 由更新器使用。
