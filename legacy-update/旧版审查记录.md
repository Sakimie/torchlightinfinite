## 截图为何没用到这套策略

静态调用链为：F8/导入/粘贴 → `vision.recognize` → `fill` → `App.calculate` → Python `engine.recommend`。英文存档建议则调用自带Node → `advise.mjs` → `english/advise.cjs` → 旧参数。

两条调用链未连接。旧界面只有三个刑具布尔值，把未开和空房合并，且“days”是剩余天数，不能直接当英文引擎的当前天数。因此不能只替换一个策略调用就宣称正确接入。

## 更新的处理

新版保留原识图、GUI、Python/Node运行库；通过新的完整核对窗口补足状态，在公开观测上计算建议。未识别信息不当作隐藏真值，模拟器的真实seed/RNG不进入决策。返回建议还需通过实际动作合法性检查。

已确认的三处差异在内存中同步修正规则和策略估值：僭越II为一人+2、煽动一个事件、口枷阈值三人。旧刑具组合收益先验停用。旧训练结果不直接继承为新版本的收益证明，历史参数是否继续使用以新验证为准。

新增EXE与原EXE并排保存，原规则、旧策略和报告不改动。更新包不重发社区源码、图片或运行库；朋友使用原完整目录加本更新即可离线运行。
